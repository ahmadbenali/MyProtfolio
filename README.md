# Personal Portfolio Website

A responsive personal developer portfolio built with semantic HTML5, custom CSS3 (Flexbox & Media Queries), and Bootstrap 5[cite: 1]. This site showcases my background, technical and soft skills, qualifications, previous projects, and contact channels[cite: 1].

## 📌 Project Overview
The goal of this project is to build an interactive, accessible, and responsive personal portfolio to demonstrate front-end fundamentals and showcase real-world projects for freelancing and technical roles[cite: 1].

### Key Sections
1. **Navigation Bar:** Fixed responsive navigation with brand logo and smooth anchor links[cite: 1].
2. **About:** Overview of background, specialization, and core focus[cite: 1].
3. **Experience:** Professional timeline highlighting engineering roles and internships[cite: 1].
4. **Qualification / Education:** Academic degree from Jordan University of Science and Technology and professional certifications[cite: 1].
5. **Skills:** Categorized technical toolsets and soft skills styled using CSS Flexbox[cite: 1].
6. **Projects:** Showcase of core applications with summaries, tech stacks, and source links[cite: 1].
7. **References:** Professional endorsements and mentorship feedback[cite: 1].
8. **Footer / Contact Details:** Direct contact information including email, phone, location, and social links[cite: 1].

---

## 🛠️ Technologies Used
- **HTML5:** Semantic markup (`<nav>`, `<section>`, `<article>`, `<footer>`, `<main>`)[cite: 1].
- **CSS3:** Custom layout styling, CSS Flexbox, resets, and styling variables[cite: 1].
- **Media Queries:** Responsive layout breakpoints ensuring optimal viewing across mobile, tablet, and desktop viewports[cite: 1].
- **Bootstrap 5:** Integrated for the navigation bar and footer components[cite: 1].

---

## 📱 Responsiveness & Testing
The site is built with a responsive-first mindset and verified across multiple viewports[cite: 1]:
- **Desktop ($\ge 992\text{px}$):** Multi-column grid/flex layouts with fully expanded horizontal navigation.
- **Tablets ($768\text{px} - 991\text{px}$):** Adjusted container margins and proportional text sizing.
- **Mobile Devices ($\le 767\text{px}$):** Stacked single-column layouts and collapsible hamburger navigation[cite: 1].
